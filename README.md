# Processamento Digital de Imagens

Repositório da disciplina Processamento Digital de Imagens (PDI).

## Sobre o projeto

Aplicação de processamento de imagens em escala de cinza (conversão de espaço de cor, filtros de suavização, detecção de bordas, equalização de histograma, etc.), implementada em duas versões: desktop (Free Pascal / Lazarus) e web (HTML/CSS/JS).

## Conteúdo

- [`Entrega1PDI/`](Entrega1PDI/README.md): aplicação desktop original (Free Pascal / Lazarus)
- [`web/`](web/README.md): porte web da mesma aplicação (HTML/CSS/JS)

## Como executar

- **Desktop:** abra `Entrega1PDI/project1.lpi` no Lazarus e rode com `F9`
- **Web:** abra `web/index.html` direto no navegador
